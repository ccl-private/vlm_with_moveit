# 安装网络说明

`install_env.sh` 默认仅在安装过程使用 HTTP 代理 `http://192.168.2.189:7890`。它不会修改系统、用户 Shell 配置或其他项目的代理设置。

`conda-forge` 通过中科大镜像直连，以承担大部分二进制依赖下载；该镜像没有 RoboStack Jazzy 通道，所以 ROS/MoveIt 专用包仍通过代理访问官方源。这一分流只对安装脚本生效。

如果代理地址发生变化，可在执行时覆盖：

```bash
MOVEIT_PROXY=http://新地址:端口 ./scripts/install_env.sh
```

临时改为直连：

```bash
MOVEIT_PROXY=direct ./scripts/install_env.sh
```

脚本同时把单次连接超时设为 30 秒、失败重试设为 8 次，并默认串行下载以适应代理的带宽波动。为避免中断后的索引缓存错误，默认不用 ZSTD 格式的索引。已下载的软件包会缓存在本目录 `.mamba_ros/pkgs`，重试时会复用，不会写到项目外。

可在服务器执行下面命令复核代理连通性：

```bash
curl -I --proxy http://192.168.2.189:7890 https://conda.anaconda.org/robostack-jazzy/linux-64/repodata.json
```
