# MoveIt 实验工作区

这是一个独立的 ROS 2 / MoveIt 2 实验目录。后续的机器人描述、启动文件、规划器、
资产、配置、构建产物和日志均应位于此目录中；不得读取、挂载、修改或写入父目录的
LeRobot-Mujoco 项目。

服务器操作系统是 Ubuntu 20.04，而 ROS 2 Jazzy 的官方二进制包面向 Ubuntu 24.04。
若采用原生路线，拟使用 micromamba/Robostack 创建此目录内的独立 Jazzy + MoveIt
环境，不使用 Docker，也不改动现有 MuJoCo/Python 环境。该独立环境已经完成安装并通过
MoveIt 冒烟测试。

实验的最终目标不是只验证 MoveIt，而是在服务器上建立一条可迁移到真机的视觉闭环：
**模拟相机 → VLM 语义理解 → 几何定位 → 任务状态机 → MoveIt 规划 → 传统机械臂控制**。
MoveIt 不负责看图，它只接收经过坐标变换和置信度检查后的抓取/放置目标，并生成受碰撞约束
的轨迹。

没有真实相机不妨碍先做视觉闭环。MuJoCo 可渲染固定相机和腕部相机的 RGB、深度图以及相机
内外参；其物体真值位姿只用于调试、监督和评测，不能作为正式控制输入。详细架构、接口、
验收标准和严格执行顺序见 [方案草案.md](方案草案.md)、[接口约定.md](接口约定.md)、
[验证计划.md](验证计划.md)、[可行性分析.md](可行性分析.md) 与 [实施路线.md](实施路线.md)。
首个可运行的模拟视觉链路见 [运行说明.md](运行说明.md)。

阶段 1 的统一 MuJoCo 场景已通过离屏和 VNC 手工验收。阶段 2 的“抓取红色杯子并放到托盘”真值任务基线已完成完整自测：MoveIt 分段规划、MuJoCo 关节回放、夹爪开闭、稳定的运动学附着、释放与托盘区域复检均成功。阶段 3 已在红色圆柱的预载 OBJ 上跑通“RGB-D 掩码点云 → CAD 表面配准 → 顶抓模板 → MoveIt 抓放”；正常速度档已将纯运动压至约 9.84 秒、VNC 约 30.8 FPS。它使用规则文本语义而非真实 VLM，且不是通用 CAD 配准。Panda 的 MuJoCo 网格与模型副本位于 `assets/panda_mjcf/`，其上游许可证随目录中的 `LICENSE` 归档。

## 目录约定

```text
src/       ROS 2 功能包：URDF、SRDF、规划器、感知接口与状态机
config/    相机、规划、控制器、感知与任务参数
assets/    本实验拥有的网格、工位和场景资产
scripts/   环境、构建与检查脚本
logs/      本地运行日志（不纳入版本控制）
*.md       方案、接口与验证文档
```

## 边界规则

ROS 环境、源代码、资产、配置和日志均留在此目录。可以在获得确认后安装必要的 Python 或
系统级依赖，但仓库文件的修改必须始终限定在 `moveit_experiment/` 中。
